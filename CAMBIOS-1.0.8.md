# MediaDownloader 1.0.8

- Actualizador online: consulta de GitHub, versiones instalada/disponible, canal configurable persistente, descarga con SHA-256 y ZIP local alternativo.
- Reutiliza el helper incremental, con confirmación, validación de base/destino, inventario permitido, respaldo y rollback.
- Código y recursos en main. Publicación automática de tag/release/portable/parche/latest.json desde un commit con versión nueva.

- Auditoría de fuentes, documentación vigente y licencia GPL-3.0-or-later; dependencias Windows fijadas.
