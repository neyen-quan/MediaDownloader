Portable para **Windows 10/11 x64**. No requiere instalar Python ni FFmpeg.

1. Descargá **MediaDownloader-1.0.0-Windows-x64.zip** (los archivos Source code son el código fuente).
2. Extraé todo el ZIP en una carpeta propia.
3. Abrí **MediaDownloader.exe**, conservando el resto de los archivos junto a él.

Para actualizar, elegí este mismo ZIP desde **Actualizar programa**. Se conserva la configuración y las descargas.

Compilación verificada: https://github.com/neyen-quan/MediaDownloader/actions/runs/39501504910
